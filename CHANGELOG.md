# Changelog

## 0.1.0-rc.1

Initial release candidate for local use:

- Four check groups: HTTPS/connectivity, WordPress leftovers, possible public credentials and production placeholders.
- English/German interface with explicit uncertainty and expandable redacted evidence.
- Bounded public HTTP(S) requests with DNS/redirect validation, pinned connections and TLS verification.
- Synthetic HTTP/TLS, hostile-input and desktop/mobile browser tests.

No hosted service is included. Results cover only a small sample; see README for detection and privacy limitations.
